# Descripción
El desafío presenta un archivo que aparenta ser un documento o imagen escaneada. El título y la categoría sugieren que la clave está oculta dentro del propio “escaneo”, ya sea en su contenido visual, estructura digital o metadatos. El objetivo es inspeccionar el archivo para revelar la información escondida.

# Solución
1. Se descarga el archivo proporcionado en el reto, el cual aparenta ser una imagen/documento escaneado.
2. Se inspecciona el archivo utilizando técnicas básicas de análisis forense: visualización detallada, ajuste de brillo/contraste o búsqueda de variaciones de color.
3. También puede revisarse la metadata del archivo o analizarlo con herramientas de esteganografía ligera, dependiendo de cómo fue ocultada la información.
4. Durante esta inspección visual/forense, aparece la información escondida que contiene la flag del desafío.
5. La flag final se obtiene directamente al identificar el contenido oculto que se revela mediante la manipulación o inspección del archivo.

# Notas adicionales
Retos de este tipo suelen esconder texto ligeramente contrastado, códigos QR poco visibles o capas ocultas dentro de una imagen que solo emergen tras modificar parámetros visuales básicos. Es común que la solución no requiera herramientas avanzadas.
