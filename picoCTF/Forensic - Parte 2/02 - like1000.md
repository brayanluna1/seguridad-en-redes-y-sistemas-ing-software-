# Descripción
El reto consiste en un archivo principal (`1000.tar`) que contiene archivos `.tar` anidados uno dentro de otro. Cada archivo extraído genera el siguiente (`1000.tar` contiene `999.tar`, este contiene `998.tar`, y así sucesivamente).  
El objetivo es automatizar la extracción de cientos de archivos `.tar` hasta llegar al archivo final (`flag.png`), el cual contiene una bandera oculta mediante esteganografía.

# Solución
1. **Descargar el archivo inicial `1000.tar`:**
   ```bash
   wget https://challenge-files.picoctf.net/c_fickle_tempest/dc6349af33fec5413fe968b12506dde81953fdab2214acb3eaaf0b96cfff5dc4/1000.tar
   ```

2. **Extraer manualmente la primera capa:**
   ```bash
   tar -xf 1000.tar
   ```

3. **Automatizar la extracción de los archivos `.tar` con Python:**
   Crear el archivo `extract_flag.py`:
   ```python
   import os

   i = 999
   while i >= 1:
       archivo_actual = f"{i}.tar"
       try:
           print(f"Extrayendo: {archivo_actual}")
           os.system(f"tar -xf {archivo_actual}")
           os.remove(archivo_actual)
       except FileNotFoundError:
           print(f"Error: {archivo_actual} no encontrado.")
           break
       i -= 1

   print("Descompresión finalizada.")
   ```

4. **Ejecutar el script:**
   ```bash
   python3 extract_flag.py
   ```

5. **Abrir `flag.png` en Stegsolve para encontrar la bandera:**
   ```bash
   wget http://www.caesum.com/handbook/Stegsolve.jar -O Stegsolve.jar
   java -jar Stegsolve.jar
   ```
   - Cargar `flag.png`
   - Navegar entre los planos de bits hasta revelar el texto `picoCTF{...}`

# Notas adicionales
- Es importante ejecutar el script en una carpeta vacía para no mezclar archivos.
- El proceso puede tardar dependiendo del hardware, ya que se generan y eliminan cientos de archivos.
- Stegsolve es esencial, ya que la bandera no es visible directamente en la imagen.
- Si un archivo TAR falta o está corrupto, el script se detendrá.
