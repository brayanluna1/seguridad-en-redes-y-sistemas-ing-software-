# Descripción

El desafío **St3g0** de picoCTF 2022 implica analizar un archivo aparentemente normal (generalmente una imagen) que contiene información oculta mediante **esteganografía**. El video de referencia (_picoCTF 2022 | Forensics | St3g0_, canal number0x01) muestra un walkthrough rápido del proceso de extracción utilizando herramientas comunes como `steghide`.

# Solución

1. **Descargar el archivo del reto** (normalmente una imagen `.jpg` o `.png`).
    
2. **Examinar la imagen** para asegurarse de que no contiene pistas visibles o metadatos relevantes.
    
3. **Usar esteganografía con `steghide`** para intentar extraer información oculta:
    
    ```
    steghide extract -sf archivo.jpg
    ```
    
4. Si el archivo requiere contraseña, probar opciones básicas o dejar vacío cuando el reto lo especifique.
    
5. Una vez extraído el contenido, abrir el archivo resultante (generalmente `.txt`) donde se encuentra la **flag** de picoCTF.
    

# Notas adicionales

- `steghide` es la herramienta estándar usada en la mayoría de los walkthroughs del reto.
    
- Este tipo de desafíos suelen ocultar información en el LSB de la imagen o usando un mensaje incrustado con clave vacía.
    
- El proceso mostrado en el video dura solo 2 minutos porque es una extracción directa sin capas adicionales de análisis.
